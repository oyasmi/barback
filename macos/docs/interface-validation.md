# 界面与交互回归验收

在 macOS 14+、Swift 6 环境执行；Linux 语法解析与 SQLite 查询验证不替代原生构建、测试与实机界面验收。

## 自动检查

```bash
make check-strings
make build
swift test --filter StoreTests
swift test --filter AppTests
```

StoreTests 覆盖结果筛选先于分页、真实总数、批量清理、确认期间新增和结束的记录保护，以及 SQLite ID 复用。AppTests 覆盖隐藏选择、快照变化、命令异常筛选、历史范围切换、暂停恢复、等长重写、日志轮转与首次创建。

## 状态栏与配置

- 深浅色、正常 / 紧凑密度、中文 / 英文分别检查；使用 64 字符名称和长命令。名称有完整提示，主按钮和 ⋯ 菜单可见；次级动作无需悬停发现。
- 同一程序在面板、配置侧栏和详情头部的图标及文字一致。服务运行用绿色圆点和竖条；一次性命令执行中用转圈、结果用勾叉和「上次…」，没有竖条。停用配置仍显示真实状态。
- 混合服务失败和命令失败 / 超时：顶部两种异常分别计数，点按后准确筛选；菜单栏失败徽标与命令异常筛选使用相同结果。
- 选中 A，再搜索或筛选到 B；不重新选择时按 ⌘↩、⌘R、⌘L 不得操作 A。删除或状态变化隐藏选中项时同样适用。打开菜单、文本输入时确认按键不会跨窗口被面板吞掉；中文输入法的候选导航和回车确认、修饰方向键的文本编辑行为保留。
- 搜索时从 9 项删至 8 项，搜索框应仍可见并可清除。完整名称、详情行及资源刷新说明可通过提示查看。
- 面板保持打开超过 3 秒，进程 CPU / RSS 更新；关闭后取消采样和时钟。
- 批量入口文字及位置固定，说明作用于全部程序。筛选时停止仍列明所有影响对象；停止与强制终止弹窗按回车默认取消。
- 配置有改动时，Esc 不得丢弃草稿；「放弃更改…」先确认，取消保留所有输入。与已有的保存失败、离开确认流程一起检查。

## 日志与历史

- A 的历史窗口保持打开，从 B 的入口打开，应切换到 B 且清除旧的结果筛选。从应用菜单打开应展示全部程序。
- 先打开一次性命令输出，再次执行同一命令；原窗口切换到新的路径，执行时间和记录 ID 同步。历史输出保持所选记录，清晰展示身份。
- 自动滚动、暂停更新独立。手动向上滚动应停在阅读位置；「回到最新」恢复自动滚动。暂停后产生输出，再恢复，即使文件不再写入也显示新内容。
- 暂停期间进行等长重写、轮转、删除再创建；恢复后展示正确内容。窗口打开期间轮转或首次生成文件后继续写入，仍可增量更新。
- 过滤显示匹配数，并明确只检索已加载内容。查找打开原生查找栏，保留上下文，支持高亮、下一处 / 上一处与 ⌘F。
- 超过 500 条历史：结果筛选能找到位于首屏之外的记录，总数准确，加载更多可访问剩余记录；快速连续切换程序和结果不得展示旧请求的内容。
- 「用当前配置再次运行…」明确采用当前已保存配置，执行中不可用且解释原因；取消不执行。服务历史不提供再次运行。
- 清理确认显示程序 / 结果范围和真实数量，包括未加载记录。确认期间新增执行或让已有执行结束，提交后这些记录仍保留；取消不删除。清理结果数量和错误均有反馈。
- 模拟日志清空权限失败，窗口显示实际错误；不存在的输出有明确提示，避免误认成成功读取的空日志。
