# 配置窗口验收

需在 macOS 13+、Swift 6 环境中执行。Linux 上的语法解析不能代替 SwiftUI 编译与窗口验收。

## 自动检查

```bash
make build
swift test --filter EnvironmentTextTests
```

环境变量测试覆盖空行、未完成输入、空值、值中的等号和空格、CRLF、敏感标记、重复变量、非法变量名及格式化往返。

## 窗口与编辑

- 默认 980×680、最小 840×560、加宽窗口，分别在深浅色模式检查。名称、命令、路径使用长文本；头部操作、字段标签、底部保存操作应可见，正文仅垂直滚动。
- 新建服务：名称、命令、执行方式、目录、运行规则可依次编辑；空环境变量默认收起。新建一次性命令时出现确认、超时、成功退出码及历史保留，不出现自动重启。
- 展开重试或日志、滚动后切换程序，再切回：恢复该程序的展开状态及顶部章节。关闭并重开窗口：恢复上次选择的程序。
- 输入环境变量时，逐字输入 `TOKEN`，再补 `=abc==`，添加空行并粘贴多行文本：不得吞字、重排或跳光标。只输入未完成行也应产生未保存状态，切换／关窗触发离开确认。
- 保存含重复变量或缺失等号的文本：不写入配置，展开环境变量并显示行号；修正后再保存成功。
- 命令为空、名称重复、目录不存在、重试数或日志大小非法时保存：滚动并聚焦首个错误；修正后区块保持展开。

## 生效与操作

- 运行中服务仅改分组或备注：显示保存，不额外提供保存并重启。
- 运行中服务修改命令或环境变量：显示保存、保存并重启；未保存时不出现立即重启。
- 选择保存：保持当前进程运行，待生效状态下提供立即重启。选择保存并重启：先成功保存，再用新配置重启；校验失败不得重启。
- 一次性命令运行中编辑配置：不出现保存并重启，保存不会重新执行命令。
- 保存期间不能再次提交或关闭窗口；保存失败后可继续编辑。放弃更改恢复原配置和环境变量文本。
- 检查 ⌘S、Esc、⌘N、⇧⌘N、⌘D、⌘⌫，以及文本复制粘贴。添加／导入位于侧栏，复制／删除位于程序菜单，删除保留确认。
